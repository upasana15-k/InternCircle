# 🚀 Upasana Kudape — Personal Portfolio Website

> A premium, interactive, multi-themed personal portfolio built with vanilla **HTML · CSS · JavaScript** — no frameworks, no external dependencies, high performance and responsiveness.

---

## ✨ Features

### 🎨 Multi-Theme System (5 Themes)
Switch themes instantly from the navbar theme toggle or via the Command Palette (Ctrl+K / Cmd+K):

| Theme | Vibe & Aesthetic |
|-------|------------------|
| 🔮 **Aurora Violet** | Light mode · soft lavender & violet palette |
| 🌑 **Eclipse Dark** | Deep dark · electric violet glow & high contrast |
| ⚡ **Future Tech** | Cyberpunk · neon cyan, gridlines & futuristic HUD |
| 📜 **Classic Editorial** | Warm sepia · editorial serif & typewriter vibes |
| 💻 **Retro Terminal** | CRT green phosphor on black · scanlines & monospaced |

### 🛠️ Interactive UI/UX
- **Command Palette (Ctrl+K)** — keyboard-first navigation and theme switcher
- **Interactive Hero Canvas** — dynamic particle network adapting its color to the active theme
- **Hero Photo Card** — custom cutout portrait with floating tech badges and glowing backdrop
- **Featured Projects Carousel** — interactive cards with deep-dive modal inspector
- **Skills Matrix** — live search and category filter tags
- **Interpolated Magnetic Cursor** — custom cursor with hover scaling and magnetic snapping
- **Audio Feedback** — Web Audio API synthesized haptic click and toggle sound effects
- **3D Tilt Cards** — perspective tilt and glare on hover
- **Scroll Reveal & Progress** — smooth entrance animations and reading progress indicator
